# awaker — знак BC2: план для Claude Code

Продолжение `PLAN.md`: редизайн уже сделан, этот план меняет только **форму знака** — кружка становится приземистой (вариант BC2: тело шире и ниже, пар выше), а иконка меню-бара — крупнее (22pt вместо 18). Цвета, поповер, тексты, анимации и логика не меняются.

Выбранные варианты из дизайн-системы:

- **меню-бар — BC2**: приземистая кружка на всю высоту 22pt;
- **кнопка — B1**: знак ≈ половина круга (как сейчас по размеру);
- **иконка приложения — A1**: знак ≈ 60% ширины плитки;
- **логотип — L2**: пар укорочен (только файлы `assets/awaker-mark*.svg`; в коде не рисуется).

Обновлены: `assets/*` (знак, иконка приложения, иконки меню-бара), `tokens.json` (`menubar-icon` = 22), `BRAND.md`, `reference/*.png`. Источник правды для чисел — этот файл и SVG в `assets/`.

## Как работать

- Ветка `redesign/mark-bc2` от `main`. Один этап — один коммит, `make` и `swift test` зелёные после каждого.
- Попиксельные тесты (`MenuBarIconTests`, `AppIconTests`) сверяют с новыми `assets/*.svg` / `awaker-app-icon.png` — они упадут, пока геометрия не обновлена; это ожидаемо.
- Отличия от плана записать в конец этого файла, раздел «Решения».

| ручка | дуга c (84, 80), r 17, штрих 12 | дуга **c (82.5, 73), r 16.5**, штрих **11**, справа, концы `butt` |
| пар, ширина / радиус | 12 / 6 | **11 / 5.5** |
| пар, 3 столбика (x, y, h) | (24,10,28) (42,0,38) (60,10,28) | **(22.5, 17, 25) (39.5, 9.5, 32.5) (56.5, 17, 25)** — низ всех на y 42 |

| контур (sleepy) | тело, утопленное на 4.5, штрих 9 | тело, утопленное на **outlineWidth / 2**, скругление снизу 22.5 − inset; концы ручки тоже `butt` |
| оптический центр | (53, 70) | **(51, 66)** |

Тело: `M11.5 50 H78.5 A4 4 0 0 1 82.5 54 V82.5 A22.5 22.5 0 0 1 60 105 H30 A22.5 22.5 0 0 1 7.5 82.5 V54 A4 4 0 0 1 11.5 50 Z`.
Ручка: `M82.5 56.5 A16.5 16.5 0 0 1 82.5 89.5`.

## Этап 1. `Drawing.swift` — сетка BC2

- `Mark.body()`, `Mark.handle()`, `Mark.steamColumns(_:)` — по таблице. `opticalCenter = (51, 66)`, `opticalHeight = 113`, `moduleWidth = 11`.
- `Mark.outline()` → `Mark.outline(inset:)`: тело, утопленное на `inset` (верх прямой, снизу радиус `22.5 − inset`). Вызывать с `inset = outlineWidth / 2`.
- `drawMark(…)`: добавить `outlineHandleWidth` (по умолчанию `outlineWidth + 0.5`) — у контура ручка чуть толще линии тела, иначе она визуально тоньше.
- Кнопка (`AwakeView`): `drawMark(in: markBox …)` с `buttonMark` 58 даёт масштаб 58 / 113 ≈ 0.513 — это вариант B1, размер не трогать. Контур sleepy: `outlineWidth: 10` (ручка 10.5).
- Пар в анимации поднимается на те же 4 единицы сетки (`steamRise`), теперь это ≈ 2pt.
- Тесты `PopoverTests` про геометрию знака — на новые числа (рамки тела, ручки, столбиков; оптический центр → центр рамки).

**Готово, когда:** `reference/AwakeButton-*.png` и `Popover-*.png` совпадают с поповером; кружка в кнопке не прыгает между sleepy / awake / screen on.

## Этап 2. Меню-бар 22pt

Эталоны: `assets/menubar-*.svg` (22×22), `reference/MenuBarIcon-*.png`.

- `Theme.Metrics.menubarIcon` = **22**; статус-айтем шириной 22 (`NSStatusItem(withLength: 22)` или `squareLength`, если он даёт 22) — ширина одинакова во всех состояниях.
- `MenuBarIcon`: масштаб **0.2**, без сдвига — сетка BC2 × 5 переходит в точки один в один (`translate(0, 0) scale(0.2)`), т. е. `center = opticalCenter × 0.2 = (10.2, 13.2)`. Оптически иконку не центрировать: в SVG она занимает высоту строки целиком (пар сверху от y 1.9, низ тела на y 21).
- Штрихи на сетке: заливка — ручка 11 (= модуль, 2.2pt); контур sleepy — `outlineWidth` 8.5 (1.7pt), ручка 9 (1.8pt).
- Тест `PopoverTests` про сетку меню-бара — на `scale 0.2`, `(0, 0) → (0, 0)`; `MenuBarIconTests` сверяет с новыми SVG.

**Готово, когда:** иконка занимает почти всю высоту меню-бара, три состояния различимы на светлом и тёмном, ширина айтема не меняется.

## Этап 3. Иконка приложения (A1)

Эталон: `assets/awaker-app-icon.svg` (плитка 180) и `awaker-app-icon.png` (1024, плитка 824).

- `Support/make-icon.swift`: геометрия знака — новая (копия из `Drawing.swift`), оптический центр (51, 66) → центр плитки (512, 512).
- Масштаб: на плитке 180 это **1.12** единицы сетки на точку, на плитке 824 — `1.12 × 824 / 180` ≈ **5.127**. Пар — полный, 3 столбика (25 / 32.5 / 25). Цвета прежние: плитка `#2E4BFF`, тело и ручка `#F1EADF`, пар `#FFC21A`.
- `make icon`, перегенерировать `Support/awaker.icns`; `AppIconTests` сверяет с новым PNG.

**Готово, когда:** в Finder и Dock — приземистая кремовая кружка с жёлтым паром, знак ≈ 60% ширины плитки.

## Решения

- **Ассеты закоммичены отдельно.** Обновлённые `assets/`, `tokens.json`, `BRAND.md`, `reference/` и этот план — первый коммит ветки; после него до этапов 2 и 3 попиксельные тесты меню-бара и иконки приложения красные, как и предупреждает план. После этапа 3 `swift test` зелёный целиком.
- **Ширина статус-айтема** — `statusItem(withLength: Theme.Metrics.menubarIcon)`, а не `squareLength`: `squareLength` равен толщине меню-бара, а она бывает и 22, и 24 (экран с вырезом), ширина должна быть ровно 22.
- **`drawMark`**: у формы с `center:scale:` появился `outlineHandleWidth: CGFloat?`; `nil` значит `outlineWidth + 0.5`. Меню-бар передаёт 9 явно (`MenuBarIcon.outlineHandleWidth`), кнопка берёт значения по умолчанию (контур 10, ручка 10.5) — `outlineWidth` по умолчанию теперь 10.
- **Центр иконки меню-бара** не задан числами, а вычисляется: `MenuBarIcon.center = Mark.opticalCenter × scale`, так `translate(0, 0) scale(0.2)` из SVG держится сам. Тест проверяет, что сетка 0…110 переходит в 0…22.
- **Иконка приложения**: в `make-icon.swift` ширина пара и ручки — константа `moduleWidth` (11), как в `Mark`.
- **Проверка.** Кнопка в трёх состояниях проверена офскрин-рендером против `reference/AwakeButton-light.png` — совпадает, кружка не сдвигается между состояниями. Меню-бар сверяется попиксельно с `assets/menubar-*.svg` тестом, в живом меню-баре не смотрел.
